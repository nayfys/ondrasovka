# Ondrašovka

Webová stránka horskej chyže Ondrašovka v Kysuckých Beskydách pod Veľkým Ondrášom.

Modrozelený jednostránkový web — hero, o nás, ponuka, galéria a kontaktný formulár.

Live: https://nayfys.github.io/ondrasovka/

## Spustenie

Otvorte `index.html` v prehliadači, alebo naservujte lokálne:

```bash
python3 -m http.server 8000
```
